Part A

HR Administrator Portal Manual

The web portal is for HR administrators only. Employees use the mobile app.

A.1 Adding employees & bulk Excel import

Single employee: Core HR → Employees → fill form → Create. Assign division, designation, and app password for mobile login.

Bulk import: Download template → complete rows → Upload. Key columns:

ColumnExample
Division CodeALKIDMA, OVERSEAS, ROYAL_OCEANS
Designation / Employment TypeMust exist in HR Masters
App PasswordCreates mobile login

A.2 Managing multi-divisions

Core HR → Divisions. Each division has a payroll type:

DivisionPayroll
Alkidma, Alqat, Royal OceansWPS (UAE)
OverseasBank transfer

Add, deactivate (soft delete), and assign employees via employee form or bulk import.

A.3 Two-tier leave approval

  1. Employee applies on mobile app → Pending manager
  2. Team lead approves on app (Team approvals) → Pending HR
  3. HR final approve/reject on portal (Leave / Approvals)

Demo team lead: ahmed@digitaldive.demo · Demo employee: fatima@digitaldive.demo

A.4 Certificate requests & issuance

Employee requests on app (Salary, Bank + bank name, NOC + destination). HR processes at Core HR → Certificates: Approve & issue or Reject. Download issued file. Client Word templates replace demo HTML at go-live.

A.5 Monthly payroll & CSV exports

Core HR → Payroll:

  1. Set period (YYYY-MM) → Generate payslips
  2. Review division summary (WPS vs bank counts)
  3. Download WPS CSV — UAE divisions only
  4. Download Bank CSV — Overseas division only
Demo CSV is simplified. Final UAE SIF column layout can be aligned when client bank specs are provided.
